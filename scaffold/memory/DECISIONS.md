# DECISIONS

Every decision Claude could not resolve from the PRD, logged here.

**HOLD** — stop and surface immediately. Security, data integrity, or anything
irreversible where the right answer isn't clear. A wrong guess beats no pause.

**PROCEED** — pick the defensible default, keep building, log it. Reversible
choices (naming, default sort order, copy) where stalling costs more.

Resolved decisions that should bind future work get promoted into
`inputs/tech-stack.md` or the PRD, so they aren't re-litigated next session.
